# Paper Review Quality Rubric

| Dimension | 0 | 2 | 4 |
|---|---|---|---|
| Source/metadata verifiability | source fabricated or absent | some items unresolved | every row traceable and status-labeled |
| Extraction completeness | required fields missing | partial fields or weak detail | all agreed fields populated or explicitly unavailable |
| Provenance traceability | no source markers | inconsistent markers | every factual sentence traceable |
| Factual/literal fidelity | findings/data altered | minor uncertainty | claims, numbers, terms, and scope match |
| Claim/evidence fidelity | unsupported findings | occasional overstatement | modality and evidence preserved |
| Dedup/triage correctness | duplicates or wrong exclusions | minor issues | documented, reproducible decisions |
| Export consistency | formats conflict or fail | minor formatting issue | all formats derive consistently from JSON |
| User-request compliance | wrong output | partial compliance | requested scope, columns, language, and formats met |

Use 1 and 3 for intermediate cases. Never average away a guardrail failure.
